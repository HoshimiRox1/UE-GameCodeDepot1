当前分工

AMainCharacter 负责 CurrentInteractTarget、Set/Clear、InteractAction 和接口调用。BP_InteractableActor 负责在 Overlap 时通知主角，并实现 InteractableInterface 的具体表现。

节点颜色

总览链路：蓝图发现目标，C++ 主角执行接口

主角不关心目标具体是什么，只通过接口统一调用；目标蓝图自己决定提示词和交互表现。

Minimal Loop

当前总流程

  1. 目标蓝图的 InteractionBox 发现主角。
  2. 目标蓝图调用主角 C++ 的 SetCurrentInteractTarget(Self)。
  3. 玩家按 IA_Interact，C++ 主角回调 Interact()。
  4. C++ 主角通过接口调用目标蓝图的 Event Interact。

BP_InteractableActor：组件、事件图表、接口函数

像虚幻蓝图编辑器一样切换查看：组件视口看结构，事件图表接 Overlap，接口函数写提示和交互表现。

Actor Blueprint

组件视口：这个 Actor 应该长什么结构

先把可交互范围和显示对象放清楚；接口不会出现在组件树里。

事件图表：Overlap 只负责通知主角

这里不要写按 E，也不要自己保存 CurrentTarget；当前目标由 C++ 主角统一管理。

接口函数：目标自己回答怎么提示、能不能交互、交互后做什么

这三个函数来自 InteractableInterface，具体实现留在蓝图里。

BP_InteractableActor 当前要接的内容

  1. 组件视口：确认有 MeshComponent 和 InteractionBox。
  2. 事件图表：BeginOverlap 调主角 SetCurrentInteractTarget(Self)。
  3. 事件图表：EndOverlap 调主角 ClearCurrentInteractTarget(Self)。
  4. 接口函数：实现 GetInteractPrompt、CanInteract、Interact。

BP_MainCharacter：只配置输入资产，不再手写交互骨架

当前主角的交互骨架已经在 C++。蓝图侧主要负责把 InteractAction 指到你的 IA_Interact 资产。

Character Blueprint

细节面板：把输入资产填给 C++ 变量

这一步是蓝图和 C++ 的最常见协作：C++ 暴露变量，蓝图实例填具体资源。

C++输入流：SetupPlayerInputComponent 绑定回调

这部分不需要你在蓝图事件图表里再接 IA_Interact。

C++交互流：主角统一持有当前目标

蓝图只调用入口函数；判断、保存、清除、按键触发都在 C++ 主角里。

BP_MainCharacter 现在要做的事

  1. 在细节面板把 InteractAction 指到 IA_Interact。
  2. 确认 DefaultMappingContext 里已经映射 IA_Interact。
  3. 不要在 BP_MainCharacter 里重复创建 CurrentInteractTarget。
  4. 不要在蓝图事件图表里重复接 IA_Interact 调接口链。

WBP_PromptWidget：Actor 上的通用交互提示

当前目标是把左上角 Print 升级成世界空间提示。提示 Widget 挂在可交互 Actor 的 WidgetComponent 上，进入范围显示，离开范围隐藏。

Widget Blueprint

控件结构：只做显示，不做交互判断

WBP_PromptWidget 不决定能不能交互，它只接收文本并显示出来。

Actor组件：把 WidgetComponent 挂在可交互物体上

因为你现在要“浮现在可交互 Actor 上”，所以提示组件放在 BP_InteractableActor 内。

显示/隐藏流程：Overlap 驱动提示词

这里按真实蓝图节点展开：WidgetComponent 只是外壳，必须先 Get User Widget Object 再 Cast 到 WBP_PromptWidget。

现在推荐接法

  1. 新建 WBP_PromptWidget，里面放 TextBlock_Prompt。
  2. 在 BP_InteractableActor 加 PromptWidgetComponent，Widget Class 指向 WBP_PromptWidget。
  3. BeginOverlap 后：PromptWidgetComponent → Get User Widget Object → Cast To WBP_PromptWidget → SetPromptWidget。
  4. SetPromptWidget 的文本输入接 GetInteractPrompt 的返回值。
  5. EndOverlap 后隐藏 Widget，并调用 ClearCurrentInteractTarget(Self)。
关键点：不能直接在 WidgetComponent 上调用 WBP 里的函数。WidgetComponent 是外壳，真正的 Widget 要通过 Get User Widget Object 拿出来。

  2. 提示词内容来自该 Actor 的 GetInteractPrompt。
  3. 按 F 仍能触发 Event Interact。
  4. 离开范围后提示词消失，再按 F 不触发。
