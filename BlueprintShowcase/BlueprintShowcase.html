交互系统最小闭环：蓝图连接示意

当前目标：进入范围显示提示，按 E 调用接口，离开范围清除目标。先用 Print String 验证链路。

BP_MainCharacter + BP_InteractableActor
总览链路 BP_InteractableActor BP_MainCharacter 验证顺序

这张图解决什么

你已经在接口里有 Interact、GetInteractPrompt、CanInteract，也在蓝图里建了查看数据变量。现在要做的是把 Actor 的接口响应和主角的当前目标变量接起来。

节点颜色

红/蓝：事件入口 紫：接口函数 绿：接口 Message 调用 黄：判断 / Branch 绿灰：变量保存

总览链路：Actor 发现目标，主角持有目标，按键触发接口

先不要做 UI。当前只验证接口调用链：Overlap 进入、保存目标、读取提示、按 E、触发 Interact、离开后清除。

Minimal Loop

照图连接顺序

  1. 先在 BP_InteractableActor 的 InteractionBox 里做 Begin / End Overlap。
  2. BeginOverlap Cast 到 BP_MainCharacter，调用 SetCurrentInteractTarget(Self)。
  3. 主角保存 CurrentInteractTarget 后调用 GetInteractPrompt Message，先 Print。
  4. 主角按 IA_Interact 时验证目标，然后调用 Interact Message。

BP_InteractableActor：变量、接口函数、Overlap 事件

这个蓝图先作为查看型交互模板。它有数据，也实现接口；但它不持有当前目标，当前目标由主角保存。

Actor Blueprint

这个蓝图里先完成这些

  1. 变量：InspectTitle、InspectDescription、InspectImage 已经没问题。
  2. 再加一个 InteractablePrompt，类型 Text，默认值 按 E 查看。
  3. GetInteractPrompt 返回 InteractablePrompt。
  4. CanInteract 返回 true。
  5. Interact 先 Print String 打印 InspectTitle。
不要急着派生具体 Actor。先把这个类拖进关卡测试，确认接口链路通了，再考虑是否派生具体相框、钥匙、门。

BP_MainCharacter：CurrentInteractTarget、设置/清除、按 E 调用

主角侧不保存查看数据，也不 Cast 到具体交互物。主角只保存一个 Actor 引用，并通过接口 Message 调用它。

Character Blueprint

主角侧蓝图连接顺序

  1. 变量：CurrentInteractTarget，类型 Actor Object Reference。
  2. 函数：SetCurrentInteractTarget(TargetActor)，先判断接口，再保存，再读提示词。
  3. 函数：ClearCurrentInteractTarget(TargetActor)，必须先做 Current == Target。
  4. 事件：IA_Interact Triggered，有效目标 + CanInteract 为 True 后调用 Interact Message。

验证顺序：先 Print，不要马上做 UI

这一步的通过标准不是界面漂亮，而是交互链路可证明。只要这三条 Print 按顺序出现，下一步再做提示 Widget 和查看 UI。

Checklist

通过标准

  1. 进入范围时能看到提示词 Print。
  2. 按 E 时能看到 InspectTitle Print。
  3. 离开范围后再按 E 不再触发交互。
  4. 这三条成立后，再做 InteractPromptWidget 和 WBP_InspectView。
