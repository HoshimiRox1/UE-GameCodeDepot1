BP_PlayerCharacter：发现可交互物并调用接口

角色蓝图只负责「找目标」和「按 E 调用」。它不关心目标是门、拼图还是箱子，真正反应交给目标 Actor 自己。

Character Blueprint

连接顺序

  1. Event Tick 进入射线检测，得到前方命中的 Actor。
  2. 用 Does Implement Interface 判断它是否实现 BPI_Interactable。
  3. True：保存到 CurrentInteractable，并显示提示；False：清空目标。
  4. IA_Interact Triggered 后先 IsValid，再调用 OnInteract Message。

节点说明

点击任意节点查看说明。默认建议先从 Event Tick 顺着白色执行线看。

BPI_Interactable：交互契约

接口不是具体逻辑，它只是规定「谁能被交互，就必须提供哪些入口」。

Blueprint Interface

接口内建议函数

  1. OnInteract(Interactor)：玩家按 E 时被调用。
  2. GetInteractPrompt()：返回 UI 上显示的提示文字。
  3. CanInteract(Interactor)：可选，用来处理上锁、距离不够等条件。

节点说明

BP_TestDoor：被调用后打开门

门蓝图只处理自己的反应。角色调用 OnInteract Message 后，这里决定是否播放开门逻辑。

Actor Blueprint

连接顺序

  1. Event OnInteract 进入门自己的逻辑。
  2. 判断 bOpened，没打开才继续。
  3. 播放 Timeline，用 Alpha 驱动旋转。
  4. 设置 bOpened = true，避免重复触发。

节点说明

BP_TestPuzzle：被调用后打开拼图 UI

拼图 Actor 的交互目标不是移动自己，而是创建一个 Widget 并把输入模式切到 UI。

Actor Blueprint

连接顺序

  1. Event OnInteract 进入拼图 Actor。
  2. Create Widget 创建拼图界面。
  3. Add to Viewport 显示界面。
  4. Set Input Mode Game and UI，让玩家能操作 UI。

WBP_InteractionPrompt：显示当前可交互提示

这个 Widget 不决定交互逻辑，只负责把当前目标返回的提示文字显示出来。

Widget Blueprint

连接顺序

  1. 角色检测到目标后，让 Widget 显示。
  2. 从目标调用 GetInteractPrompt Message。
  3. 把返回 Text 接到 SetText。
  4. 目标消失时隐藏 Widget。
