# BP_SafeBox

**变量**
- `bIsUnlocked` - Boolean
- `TargetAngle` - Float
- `Tolerance` - Float
- `SafeBoxPanelClass` - Widget Class Reference（`WBP_SafeBoxPanel`）

**职责**
- 负责实现 `Interact` 接口
- 保存谜题目标角度，并在创建 UI 时传给 `WBP_SafeBoxPanel`
- 监听 `WBP_SafeBoxPanel` 的解锁事件，并把 `bIsUnlocked` 改为 `true`
- 当 `bIsUnlocked` 为 `true` 的时候，关闭 `WBP_SafeBoxPanel`，恢复玩家输入，并执行保险箱打开表现

## 接口

获取 `BP_PlayerController` 并创建 `WBP_SafeBoxPanel`，添加到视口，切换输入模式。

建议流程：
```text
Interact
  -> Get Player Controller
  -> Create Widget WBP_SafeBoxPanel
  -> 调用 WBP_SafeBoxPanel 继承到的 C++ 初始化函数：SetSafeDialConfig(TargetAngle, Tolerance)
  -> Bind Event to OnSafeDialSolved
  -> Add To Viewport
  -> Set Input Mode Game And UI 或 UI Only
  -> Show Mouse Cursor = true
```

# C++ 基类：USafeBoxPanel

> 目标：把旋钮算法、状态机和解锁判定从蓝图里拿出来，避免 `WBP_SafeBoxPanel` 里出现一大串角度计算节点。

**继承关系**
```text
UUserWidget
  -> USafeBoxPanel          // C++：旋钮算法和判定
      -> WBP_SafeBoxPanel   // 控件蓝图：UI 绑定和表现
```

**现有 C++ 文件**
- `Source/AIGame/SafeBoxPanel.h`
- `Source/AIGame/SafeBoxPanel.cpp`

> `WBP_SafeBoxPanel` 的 Parent Class 需要改成 `SafeBoxPanel`。以后文档里说的 C++ 基类，指的就是 `USafeBoxPanel`，不是额外再新建一个 `USafeBoxPanelBase`。

**C++ 保存的状态**
- `TargetAngle` - Float：成功分界线角度，例如 `135`
- `Tolerance` - Float：容差，例如 `3-5`
- `CurrentAngle` - Float：当前旋钮累计角度，始终归一化到 `0-360`
- `bIsDragging` - Boolean：是否正在长按拖动旋钮
- `LastMouseAngle` - Float：上一帧鼠标相对旋钮中心的角度
- `DialCenterInWidget` - Vector2D：旋钮中心点在 Widget 本地空间里的位置
- `bSolved` - Boolean：是否已经解锁，防止重复广播

**事件分发器**
- `OnDialAngleChanged(CurrentAngle)`：C++ 算完新角度后通知蓝图刷新旋钮显示
- `OnSafeDialSolved`

**暴露给蓝图调用的函数**
- `SetSafeDialConfig(TargetAngle, Tolerance)`：由 `BP_SafeBox` 创建 UI 后传入谜题配置
- `SetDialCenterInWidget(DialCenter)`：由 `WBP_SafeBoxPanel` 在构造后传入旋钮中心点
- `BeginDialDrag(MouseLocalPosition)`：鼠标按下时调用
- `UpdateDialDrag(MouseLocalPosition)`：鼠标移动时调用
- `EndDialDrag()`：鼠标松开时调用
- `GetCurrentAngle()`：蓝图需要主动读取当前角度时使用

**C++ 职责**
- 负责记录拖拽状态
- 负责把鼠标本地坐标转换成绕中心点的角度
- 负责计算本帧角度差 `DeltaAngle`
- 负责处理跨 `0/360` 的角度归一化
- 负责把 `CurrentAngle` 限制在 `0-360`
- 负责判断是否进入 `TargetAngle ± Tolerance`
- 负责广播 `OnDialAngleChanged` 和 `OnSafeDialSolved`

**C++ 不负责**
- 不负责创建保险箱 Widget
- 不负责恢复玩家输入
- 不负责播放保险箱打开表现
- 不负责决定旋钮图片、背景图、按钮样式
- 不直接知道 `BP_SafeBox` 的业务状态

# WBP_SafeBoxPanel

> `WBP_SafeBoxPanel` 不再实现旋钮算法，只继承 `USafeBoxPanel`，把鼠标事件和 UI 控件连接到 C++ 提供的函数和事件。

**控件树**
Canvas
- Image_SafeBoxBackground
- Image_SafeBoxDial
- FullScreenHitArea

**职责**
- 继承 `USafeBoxPanel`
- 在 Construct / 初始化时，把旋钮中心位置传给 `SetDialCenterInWidget`
- 鼠标按下时，把鼠标本地坐标传给 `BeginDialDrag`
- 鼠标移动时，把鼠标本地坐标传给 `UpdateDialDrag`
- 鼠标松开时调用 `EndDialDrag`
- 监听 `OnDialAngleChanged(CurrentAngle)`，把 `CurrentAngle` 应用到 `Image_SafeBoxDial.RenderTransform.Angle`
- 监听或向外转发 `OnSafeDialSolved`，让 `BP_SafeBox` 修改 `bIsUnlocked`
- 可选：处理关闭按钮或 Esc 的 UI 侧回调，但不直接恢复玩家输入

## 旋钮算法

核心思路仍然不变：不要把鼠标移动量直接当成旋钮角度，而是把“鼠标当前位置相对旋钮中心点的方向”转换成角度，再用本次角度减去上一次角度，得到这一帧旋钮应该增加或减少多少度。

区别是：下面这套计算逻辑放在 `USafeBoxPanel` 里，不再要求用蓝图节点手动拼出来。

**鼠标按下**
```text
WBP_SafeBoxPanel.FullScreenHitArea -> OnMouseButtonDown
  -> 获取 MouseLocalPosition
  -> 调用 C++ BeginDialDrag(MouseLocalPosition)

C++ BeginDialDrag(MouseLocalPosition)
  -> bIsDragging = true
  -> MouseLocalPosition - DialCenterInWidget
  -> Atan2(Y, X)
  -> Radians To Degrees
  -> LastMouseAngle = 结果
```

**鼠标移动**
```text
WBP_SafeBoxPanel.FullScreenHitArea -> OnMouseMove
  -> 获取 MouseLocalPosition
  -> 调用 C++ UpdateDialDrag(MouseLocalPosition)

C++ UpdateDialDrag(MouseLocalPosition)
  -> Branch: bIsDragging == true
  -> Direction = MouseLocalPosition - DialCenterInWidget
  -> CurrentMouseAngle = RadiansToDegrees(Atan2(Direction.Y, Direction.X))
  -> DeltaAngle = CurrentMouseAngle - LastMouseAngle
  -> DeltaAngle = Normalize Axis(DeltaAngle)    // 压到 -180 ~ 180，解决 359 到 1 度的跨零问题
  -> CurrentAngle = CurrentAngle + DeltaAngle
  -> CurrentAngle = Normalize To 0-360(CurrentAngle)
  -> LastMouseAngle = CurrentMouseAngle
  -> OnDialAngleChanged.Broadcast(CurrentAngle)
  -> CheckSolved
```

**鼠标松开**
```text
WBP_SafeBoxPanel.FullScreenHitArea -> OnMouseButtonUp
  -> 调用 C++ EndDialDrag()

C++ EndDialDrag()
  -> bIsDragging = false
```

**角度归一化**
```text
Normalize To 0-360:
  Angle = Fmod(Angle, 360)
  if Angle < 0:
    Angle = Angle + 360
```

这一步由 C++ 统一实现。蓝图侧不再需要关心 `Fmod`、负角度修正、`Normalize Axis` 的组合方式。

**成功判定**
```text
CheckSolved:
  if bSolved == true:
    return
  Error = Abs(Normalize Axis(CurrentAngle - TargetAngle))
  if Error <= Tolerance:
    bSolved = true
    OnSafeDialSolved.Broadcast()
```

这里也要用 `Normalize Axis`，否则会出现这种错误：
```text
CurrentAngle = 359
TargetAngle = 1
普通相减误差 = 358
真实角度误差 = 2
```

**节点重点**
- `Atan2`、`Radians To Degrees`、`Normalize Axis`：放在 C++，不在控件蓝图里拼
- `Set Render Transform Angle`：保留在 `WBP_SafeBoxPanel`，只负责旋转旋钮图片，不旋转保险箱背景
- `OnDialAngleChanged`：C++ 到蓝图的显示刷新事件
- `OnSafeDialSolved`：C++ 到保险箱业务逻辑的解锁事件

**调试顺序**
1. 先在 C++ 或蓝图事件里打印 `CurrentAngle`，确认鼠标绕圈时角度在变化
2. 再监听 `OnDialAngleChanged`，确认事件能持续打到 `WBP_SafeBoxPanel`
3. 再让 `Image_SafeBoxDial` 跟着 `CurrentAngle` 旋转
4. 最后测试 `TargetAngle ± Tolerance` 是否触发 `OnSafeDialSolved`

如果发现顺时针和逆时针方向反了，不要重做算法，只需要把这一句改成：
```text
DeltaAngle = -DeltaAngle
```
## 关闭/取消界面的流程

第一版先用 `Esc` 关闭界面，不做复杂返回按钮。

**新增输入**
- `IA_ClosePanel` - Input Action：绑定键盘 `Esc`

**推荐职责**
- `BP_PlayerController` 负责接收 `Esc`，因为它本来就负责 UI 生命周期和输入模式切换
- `WBP_SafeBoxPanel` 不直接恢复玩家控制，只提供 `RemoveFromParent` 或 `OnSafeDialCancelled` 事件
- `BP_SafeBox` 只关心是否解锁，不需要关心玩家按了哪个键取消 UI

**打开界面时记录引用**
```text
BP_PlayerController
  -> Create Widget WBP_SafeBoxPanel
  -> Promote To Variable: CurrentSafeBoxPanel - WBP_SafeBoxPanel Object Reference
  -> Add To Viewport
  -> Set Input Mode Game And UI 或 UI Only
  -> Show Mouse Cursor = true
```

**Esc 关闭流程**
```text
IA_ClosePanel / Keyboard Escape Triggered
  -> Branch: IsValid(CurrentSafeBoxPanel)
  -> CurrentSafeBoxPanel.RemoveFromParent
  -> CurrentSafeBoxPanel = None
  -> Set Input Mode Game Only
  -> Show Mouse Cursor = false
  -> 恢复角色移动 / 恢复角色输入
```

**解锁成功时也走同一套关闭流程**
```text
WBP_SafeBoxPanel.OnSafeDialSolved
  -> BP_SafeBox.bIsUnlocked = true
  -> BP_PlayerController.CloseSafeBoxPanel
  -> 播放保险箱打开表现 / 允许拾取奖励
```

这样 `Esc` 取消和“破解成功后关闭”不会写成两套逻辑。后续如果要加关闭按钮，只需要让按钮调用同一个 `CloseSafeBoxPanel`。

> [!note] Esc 输入兜底
> 如果 `Set Input Mode UI Only` 后 `BP_PlayerController` 收不到 `Esc`，第一版可以先改成 `Set Input Mode Game And UI`。如果仍然不稳定，再让 `WBP_SafeBoxPanel` 设置可聚焦，并在 Widget 的 `OnKeyDown` 里处理 `Escape`。
